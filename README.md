## 🕒 Timeline: Days 1–12  
### 🎯 Objective  
Build strong fundamentals in cybersecurity, networking, cryptography, and set up a professional hacking lab.

## ⚙️ Steps Completed

### 1️⃣ Lab Setup  
- Installed **kali linux**  
- Configured **Kali Linux** (attacker)  
- Installed **Metasploitable2** / **DVWA** (target)  
- Set up a **Host-Only Adapter network**

### 2️⃣ Linux Fundamentals  
- File System Navigation: `cd`, `ls`, `pwd`  
- File Permissions: `chmod`, `chown`  
- Package Management: `apt`, `dpkg`  
- Networking Commands: `ifconfig`, `ping`, `netstat`, `traceroute`

### 3️⃣ Networking Basics  
- OSI Model & TCP/IP Suite  
- DNS, HTTP/HTTPS  
- IP Addressing, Subnetting, NAT

### 4️⃣ Cryptography Basics  
- Symmetric vs Asymmetric Encryption  
- Hashing: **MD5, SHA256**  
- Digital Certificates, SSL/TLS  
- Hands-on: Encrypt/Decrypt with OpenSSL

### 5️⃣ Tool Familiarization  
- Wireshark (Packet Capture)  
- Nmap (Network Scanning)  
- Burp Suite (Web Proxy)  
- Netcat (Network Debugging)
